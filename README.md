# Cairn Study Journal
Cairn is a responsive web app for self-paced learners. Set a target date for each course and Cairn works out whether you’re ahead or behind and what to focus on today. Log study sessions, capture insights, questions and interests as you learn, and let the app resurface older notes for review. Before an exam, it compiles your own notes into a revision sheet.

Built as a project for the Web Application Development course (DLBCSPJWD01).
